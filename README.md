## 3. 作業問題回答
- **問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？**
  因為加上引號的 `"4"` 在 Python 中屬於字串（`str`）型別，代表的是文字符號而非數值。在計算每人費用時需要執行除法（`total_amount / num_people`），Python 不允許將浮點數（`float`）直接除以字串，否則會發生 `TypeError` 錯誤，因此必須先用 `int()` 轉成整數才能進行數學運算。

- **問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**
  - **計算過程**：先扣折價券後的剩餘餐費為 `1200 - 100 = 1100` 元；以此計算 10% 服務費為 `1100 × 0.10 = 110` 元；最終應付總額會變成 `1100 + 110 = 1210` 元。
  - **差異原因**：因為服務費的計算基準（母數）不同。題目規定服務費是以「原始餐費 1,200 元」計算（服務費 120 元），而先扣折價券會讓計算服務費的金額減少 100 元，導致服務費跟著少了 `100 × 10% = 10` 元，總金額因此從 1,220 元變成 1,210 元。
